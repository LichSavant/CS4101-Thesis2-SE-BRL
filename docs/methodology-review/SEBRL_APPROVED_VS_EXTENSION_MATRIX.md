## Option A: implemented components, remaining minimum and allowed claims

Implemented: codebook, modality routing, preprocessing/source spans, rules/conditional
ports, strict schemas/reference metadata, peer deterministic slot mapping, conventional
and fusion infrastructure, four-family/nested/calibration/selection/persistence code,
prototype UI/API and proposed R22 Email integration. These are not one accepted
frozen research package yet.

Minimum remaining work: (1) choose/freeze the exact deterministic instrument and
conformance cases; (2) reconcile partial availability, aliases and matched predictor
dictionaries; (3) resolve ordinary parser/product correctness issues and R22
acceptance; (4) obtain authentic population/label/license/custody/group/exposure
facts; (5) freeze actual research settings; (6) obtain exact authorization and run
no-fit accepted-data conformance before any experiments; (7) execute controlled
phishing comparisons, system freeze and valid final evaluation under separate
permission; (8) write results from actual accepted evidence. Do not require a
behavioral neural learner or expert annotation for this option.

Acceptable current claim: “The source implements and synthetically tests
modality-bounded deterministic evidence and a proposed integration boundary.”
After approved research execution, report measured phishing-classification,
calibration/risk/software-conformance results with their actual limitations.
Unsupported now: incremental E3 benefit, accepted final classifier/calibration,
expert behavioral ground truth, recipient vulnerability, implicit tactic accuracy,
causal explanations or production certification.

## Option B: preservation and proposed scientific amendments

The existing source can be retained without using it in baseline experiments.
If the adviser accepts a study extension, propose questions such as:

- **B-RQ1:** On an independently authorized/reference-defined artifact challenge
  set, what eligible-candidate coverage, selective correctness, false-support and
  abstention does constrained NLI review show beyond the frozen rule instrument?
- **B-RQ2:** Does the frozen context/evidence/identity eligibility policy reduce
  unsupported review candidates across explicit, implicit, quoted, negated,
  hypothetical and unavailable cases, without changing deterministic labels?
- **B-RQ3:** Can source-faithful spans, provenance and bounded resource/failure
  behavior be maintained under the accepted NLI review path, and at what measured
  review/runtime cost in the approved environment?

These are proposals, not newly adopted objectives. The baseline LR E3–E1 research
question is not replaced by them. A meaningful semantic result requires an
accepted operational construct and reference standard. Decide whether qualified,
independent, blinded human reference work is appropriate and approved; explicitly
handle uncertain/missing/identity cases and separate adjudications if adopted.
Never use synthetic declared-human fixtures or the same deterministic rule as
independent semantic truth. If no appropriate accepted standard can be obtained,
restrict claims to candidate-interface engineering and defer semantic efficacy.

Freeze exact model/tokenizer/weights/hypotheses/source identity, language and
sampling/exposure scope, eligibility, comparison design, review metrics,
uncertainty/denominators, seeds/budgets/failure handling and claims before any
inference. NLI labels remain uncalibrated candidates; no accepted autonomous
indicator outcome, behavioral z value or calibrated phishing risk follows.

Effects and risks: added data/reference/privacy/review burden; corpus/identity
bias; NLI hypothesis/language sensitivity; source/format leakage; context over-
filtering and untested implicit reasoning; resource/version dependence; and
misleading stronger title/novelty claims. These are not resolved by retaining
code, matching version strings or the 50 software cases.

## Recommendation

Choose **A for the current thesis**, retain B as a separate, clearly labeled
optional engineering branch/appendix/future work. This preserves useful work
with the smallest methodological change: clarify manuscript claims and freeze
operational conformance, without inventing human data, a behavioral model or a
new semantic-performance result. If B is selected for actual research, obtain
explicit adviser decisions and a bounded validation amendment first. Neither
option opens existing research gates or grants R22 acceptance.
